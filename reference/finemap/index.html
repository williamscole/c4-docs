    API reference: c4.finemap¶

    The functions behind c4 finemap; see Fine-mapping for how they fit together.

    Fine-mapping: per-session LD reference panels built from the data catalog, the loci to fine-map, and SuSiE-RSS on each locus.

    c4 finemap setup converts a cohort's genetic data (a dna: entry in catalog.yaml, named <cohort>.<entry> e.g. demo.imputed) into one plink2 pgen fileset per chromosome:

    <dir>/<panel name>/
    chr6.pgen / .pvar / .psam    variant IDs are CHROM:POS:REF:ALT
    chr6.log                     plink2 log
    samples.keep                 the samples kept (#IID)
    settings.json                source, build, filters, and the chromosomes built

    defaults to $TMPDIR, so a panel lasts as long as the session or Slurm job that built it. Imputed dosages (FORMAT/DS) are kept in the pgen.

    Samples are Cohort.samples() for that data set (the id_map's samples, minus patients marked drop=1), optionally narrowed to populations (--pops, for a reference panel such as kgp) and to a --keep file. A reference panel's VCFs can hold more samples than that (kgp b38: 3,202 VCF samples, 2,504 kept).

    run_finemap(gwas_file, loci_file, panel, build, out, panel_root=None, locus_ids=None, n=None, L=10, coverage=0.95, min_abs_corr=0.5, estimate_residual_variance=None, drop_ambiguous=False, max_variants=20000, in_sample=False, catalog=None, chrom_col=None, pos_col=None, ref_col=None, alt_col=None, p_col=None, z_col=None, beta_col=None, se_col=None, n_col=None, ea_col=None, rscript='Rscript') ¶

    Fine-map every locus in loci_file with SuSiE-RSS, using GWAS z-scores and LD from a panel made by setup_panel().

    Every GWAS variant in a locus is used, whatever its p-value. Variants are matched to the panel on CHROM:POS and alleles (REF/ALT swaps allowed), z is oriented to the panel ALT allele, and LD comes from the panel's dosages (hard calls if the panel was built without DS).

    in_sample says the GWAS was run on the panel's own genotypes (refused for a reference panel such as kgp). SuSiE then estimates the residual variance (unless estimate_residual_variance is False), drop_ambiguous is refused (strand can't differ), and loci whose N differs from the panel's sample count, or with kriging flags, get a note. estimate_residual_variance defaults to True in-sample, else False.

    Writes

    {out}.cs.tsv one row per credible set: purity, lead by PIP, lead and min p by GWAS p {out}.cs_members.tsv every CS member with its full GWAS row, PIP and alpha {out}.pip.tsv every fine-mapped variant: z, p, PIP, CS, kriging diagnostics {out}.summary.tsv one row per locus: status, variant counts, drop reasons, N, s, n_cs {out}.dropped.tsv GWAS variants in a locus that weren't fine-mapped, with DROP_REASON {out}.run.json inputs, panel settings, parameters and versions

    Returns:

    Type Description
    dict

    Run summary dict.

    fine_map_locus(locus, gwas, gwas_chrom, gwas_pos, cols, eff, panel_dir, pvar, n_samples, n=None, dosage=False, rscript='Rscript', L=10, coverage=0.95, min_abs_corr=0.5, estimate_residual_variance=False, drop_ambiguous=False, max_variants=20000, in_sample=False) ¶

    Fine-map one locus. Returns {"summary": dict, "pip": DataFrame, "cs": [rows], "members": [DataFrames], "dropped": DataFrame}. Problems that only affect this locus are reported in summary["status"] rather than raised; things worth a look go in summary["notes"].

    With in_sample (the GWAS was run on the panel's own genotypes), a sample size that differs from the panel's and any kriging flags are noted, since with in-sample LD neither should happen.

    effect_columns(columns, cols, z_col=None, beta_col=None, se_col=None, n_col=None, ea_col=None) ¶

    Which GWAS columns give z, N and the effect allele.

    z is read directly (Z_STAT, Z, T_STAT), else BETA/SE, else log(OR)/SE. The effect allele is A1 / EFFECT_ALLELE / ALLELE1, else the ALT column.

    Returns {"z", "beta", "or", "se", "n", "ea": column or None, "z_from": text}.
