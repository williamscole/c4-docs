    From R¶

    The c4r package loads data from R through the same data catalog as Python's cohort(), and returns ordinary data.frames. It is a thin wrapper: the Python c4 package does the work, through reticulate.

    Install¶

    You need the Python install first (setup), plus the R package reticulate. Then, from the root of the c4 repository:

    R CMD INSTALL c4r

    or, in R, install.packages("c4r", repos = NULL, type = "source").

    Set up¶

    Tell c4r which Python has c4 installed, once per session:

    library(c4r)
c4r_setup(python = "/path/to/venv/bin/python")   # or a virtualenv directory

    To skip this step, set C4_PYTHON in ~/.Renviron:

    C4_PYTHON=/path/to/venv/bin/python

    To use another catalog, e.g. the demo one, pass it to setup: c4r_setup(catalog = "examples/demo/catalog.yaml").

    Check the setup

    From the repository root, C4_PYTHON=/path/to/venv/bin/python Rscript c4r/tests/run_demo.R runs every method on the demo cohort and ends with "All c4r checks passed."

    Load data¶

    The cohort object has the same methods as in Python, called with $ instead of .. The examples use the fake demo cohort, shown with its data folder as /data/lab.

    demo <- cohort("demo")          # prints what's available, as in Python

    Everything else¶

    demo$path("dna.imputed", chrom = 6)        # "/data/lab/demo/dna/chr6.dose.vcf.gz"
demo$paths("dna.imputed")[["6"]]           # all chromosomes, named by number
demo$describe("OS_mo")                     # Overall survival (months) (numeric)
demo$id_map()                              # patient_id / exome_id / array_id / imputed_id
demo$dropped_patients()                    # "P006"
demo$check()                               # problems with the catalog, if any

    How R and Python differ¶

    Python R
    Call a method demo.load("pheno") demo$load("pheno")
    Options keep_dropped=True keep_dropped = TRUE
    Missing values NaN / None NA
    HLA genotype columns HLAgenotype objects text, e.g. "A*02:01/A*24:02"
    Merge report and notes printed R messages; hide with verbose = FALSE or suppressMessages()
    Errors Python exceptions R errors with the same message

    For example, an invalid template value:

    demo$load("hla.hibag", panel = "martian")

    Error: ValueError: Invalid panel='martian' for 'hla.hibag.raw'. Choose from: ['european', 'african', 'asian', 'multiethnic']

    Only data loading is wrapped. The command-line tools (c4 dosages, c4 survival, …) work the same whether you use R or Python; see Command line.
